Classes ​

Une classe est un modèle (blueprint) qui décrit les caractéristiques et les comportements d'un type d'objet. C'est la brique de base de la programmation orientée objet.

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Définir une classe en Java avec des attributs et des méthodes
  • Distinguer attributs d'instance et attributs de classe
  • Appliquer les conventions de nommage pour les classes et leurs membres
  • Modéliser une entité du monde réel sous forme de classe

  • Définir une classe en Java avec des attributs et des méthodes
  • Différencier attributs d'instance et attributs de classe

Qu'est-ce qu'une classe ? ​

En POO, une classe décrit :

  • Les attributs (caractéristiques) : ce que l'objet est
  • Les méthodes (comportements) : ce que l'objet fait

Une classe est une description abstraite, pas un objet concret. C'est comme un plan architectural : le plan décrit la maison, mais ce n'est pas la maison elle-même.

Analyse du monde réel ​

Avant de coder une classe, on observe l'entité du monde réel et on identifie :

  • Ses caractéristiques fixes ou variables (ex. : couleur, taille, état)
  • Ses comportements propres (ce qu'elle fait d'elle-même)
  • Son contexte d'utilisation (dans quel domaine l'utilise-t-on ?)

Contexte = représentation différente

La même entité peut se modéliser différemment selon le domaine. Un étudiant dans un système académique a un numéro matricule et des notes. Un étudiant dans un système de transport en commun a une carte d'abonnement et des trajets.

Définir une classe en Java ​

java
package ca.csfoy.w20.tennis;

public class BalleDeTennis {

    // Attributs (privés par convention)
    private String couleur;
    private double diametre;
    private int nombreRebonds;

    // Méthode d'instance
    public void rebondir() {
        this.nombreRebonds++;
    }

    public int getNombreRebonds() {
        return this.nombreRebonds;
    }

    public String getCouleur() {
        return this.couleur;
    }
}

Structure d'une classe ​

[modificateur] class [NomDeLaClasse] {

    // 1. Constantes (static final)
    // 2. Attributs statiques (static)
    // 3. Attributs d'instance
    // 4. Constructeurs
    // 5. Méthodes d'instance
    // 6. Méthodes statiques
    // 7. Getters / Setters
}

Noms de classe

Une classe représente un concept ou une entité du domaine. Son nom doit être un substantif (nom, pas verbe), au singulier. Évite les noms vagues comme Manager, Handler ou Processor.

Attributs de classe vs attributs d'instance ​

java
public class Etudiant {

    // Attribut de CLASSE (partagé par tous les étudiants)
    // Voir la section Membres statiques pour plus de détails
    private static int nombreTotal = 0;

    // Attributs d'INSTANCE (propres à chaque étudiant)
    private String prenom;
    private String nom;
    private int numeroMatricule;
}
Exemple complet - classe Produit
java
package ca.csfoy.w20.inventaire;

public class Produit {

    private static final double TAUX_TVQ = 0.09975;

    private String nom;
    private double prixAvantTaxes;
    private int quantiteEnStock;

    public String getNom() {
        return this.nom;
    }

    public double getPrixAvantTaxes() {
        return this.prixAvantTaxes;
    }

    public double getPrixAvecTaxes() {
        return this.prixAvantTaxes * (1 + TAUX_TVQ);
    }

    public int getQuantiteEnStock() {
        return this.quantiteEnStock;
    }

    public boolean estDisponible() {
        return this.quantiteEnStock > 0;
    }
}
