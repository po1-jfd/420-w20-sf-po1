equals et hashCode ​

En Java, comparer deux objets avec == compare leurs adresses mémoire. Pour comparer leur contenu, il faut implémenter les méthodes equals() et hashCode().

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Distinguer comparaison superficielle (==) et comparaison profonde (equals)
  • Implémenter la méthode equals() correctement
  • Implémenter hashCode() en respectant son contrat avec equals()
  • Différencier un objet Entité d'un objet Valeur

Le problème de == avec les objets ​

== compare les références (adresses mémoire), pas le contenu.

java
String s1 = new String("Alice");
String s2 = new String("Alice");

System.out.println(s1 == s2);       // false - deux objets différents en mémoire
System.out.println(s1.equals(s2));  // true  - même contenu

Comparaison superficielle vs profonde ​

TypeMécanismeCompare quoi
Superficielle==L'adresse mémoire (référence)
Profonde.equals()Le contenu de l'objet

Implémenter equals() ​

java
public class Point {
    private int x;
    private int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    @Override
    public boolean equals(Object obj) {
        // 1. Même référence ?
        if (this == obj) return true;
        // 2. null ou mauvais type ?
        if (obj == null || this.getClass() != obj.getClass()) return false;
        // 3. Comparer les champs significatifs
        Point autre = (Point) obj;
        return this.x == autre.x && this.y == autre.y;
    }
}

Implémenter hashCode() ​

hashCode() retourne un entier utilisé par les structures de données basées sur le hachage (HashMap, HashSet). Son contrat avec equals() :

Si a.equals(b) est vrai, alors a.hashCode() == b.hashCode() doit être vrai.

java
import java.util.Objects;

@Override
public int hashCode() {
    return Objects.hash(this.x, this.y);  // utilise les mêmes champs que equals()
}

Toujours implémenter les deux ensemble

Si tu redéfinis equals(), tu dois aussi redéfinir hashCode(). L'inverse est aussi vrai. Intellij peut générer les deux automatiquement via Alt+Insérer → equals() and hashCode().

Entité vs Objet Valeur ​

La façon dont on compare des objets dépend de leur sémantique :

Entité (Entity) ​

Un objet défini par son identité unique (ex. : un étudiant a un numéro matricule unique). Deux étudiants avec le même prénom sont des personnes différentes.

java
public class Etudiant {
    private int numeroMatricule;
    private String prenom;
    private String nom;

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || this.getClass() != obj.getClass()) return false;
        Etudiant autre = (Etudiant) obj;
        return this.numeroMatricule == autre.numeroMatricule;  // identité = matricule seulement
    }

    @Override
    public int hashCode() {
        return Objects.hash(this.numeroMatricule);
    }
}

Objet Valeur (Value Object) ​

Un objet défini par tous ses attributs (ex. : un point, une couleur, un montant). Deux points avec les mêmes coordonnées sont identiques.

java
public class Montant {
    private double valeur;
    private String devise;

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || this.getClass() != obj.getClass()) return false;
        Montant autre = (Montant) obj;
        return Double.compare(this.valeur, autre.valeur) == 0
            && this.devise.equals(autre.devise);  // tous les champs comptent
    }

    @Override
    public int hashCode() {
        return Objects.hash(this.valeur, this.devise);
    }
}

Règle pratique

  • Entité : l'identité provient d'un identifiant unique (ID, matricule, code). Compare sur cet identifiant uniquement.
  • Objet Valeur : deux instances avec les mêmes valeurs sont interchangeables. Compare tous les champs significatifs.

Utilisation dans les collections ​

equals() et hashCode() sont automatiquement utilisés par ArrayList.contains(), HashSet, HashMap, etc.

java
HashSet<Point> points = new HashSet<>();
points.add(new Point(1, 2));
points.add(new Point(1, 2));  // doublon si equals() et hashCode() sont corrects

System.out.println(points.size());  // 1 si correctly implemented, 2 sinon
