Constructeurs ​

Un constructeur est une méthode spéciale qui s'exécute lors de la création d'un objet. Il garantit que l'objet est dans un état valide dès son instantiation.

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Écrire un constructeur simple avec paramètres
  • Surcharger un constructeur (plusieurs constructeurs)
  • Déléguer entre constructeurs avec this()
  • Appliquer le principe DRY dans la conception des constructeurs
  • Garantir qu'un objet est toujours dans un état valide à la création

Constructeur de base ​

Un constructeur a le même nom que la classe et n'a pas de type de retour.

java
public class Etudiant {
    private String prenom;
    private String nom;
    private int age;

    // Constructeur
    public Etudiant(String prenom, String nom, int age) {
        if (prenom == null || prenom.isBlank()) {
            throw new IllegalArgumentException("Le prénom ne peut pas être vide.");
        }
        if (nom == null || nom.isBlank()) {
            throw new IllegalArgumentException("Le nom ne peut pas être vide.");
        }
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("Age invalide : " + age);
        }
        this.prenom = prenom;
        this.nom = nom;
        this.age = age;
    }
}

Constructeur par défaut ​

Si tu n'écris aucun constructeur, Java génère un constructeur sans paramètre implicite. Dès que tu écris un constructeur explicite, le constructeur par défaut n'est plus disponible.

java
// Si aucun constructeur n'est déclaré :
Etudiant e = new Etudiant();  // fonctionne (constructeur par défaut implicite)

// Si un constructeur avec paramètres est déclaré :
Etudiant e = new Etudiant();  // ERREUR - le constructeur sans paramètre n'existe plus
Etudiant e = new Etudiant("Alice", "Tremblay", 20);  // fonctionne

Surcharge de constructeurs ​

Une classe peut avoir plusieurs constructeurs avec des signatures différentes. C'est utile quand certaines données sont optionnelles.

java
public class CommandeRestaurant {
    private String plat;
    private String note;
    private boolean estPourEmporter;

    // Constructeur complet
    public CommandeRestaurant(String plat, String note, boolean estPourEmporter) {
        if (plat == null || plat.isBlank()) {
            throw new IllegalArgumentException("Le plat ne peut pas être vide.");
        }
        this.plat = plat;
        this.note = note;
        this.estPourEmporter = estPourEmporter;
    }

    // Constructeur simplifié - commande sur place, sans note
    public CommandeRestaurant(String plat) {
        this(plat, null, false);  // délègue au constructeur complet
    }

    // Constructeur avec note mais sur place
    public CommandeRestaurant(String plat, String note) {
        this(plat, note, false);  // délègue au constructeur complet
    }
}

Délégation avec this() ​

this() appelle un autre constructeur de la même classe. Il doit être la première instruction du constructeur.

java
public CommandeRestaurant(String plat) {
    this(plat, null, false);  // DOIT être en premier
    // Autre code ici si nécessaire...
}

DRY et constructeurs

La délégation via this() applique le principe DRY : la validation et l'initialisation sont centralisées dans un seul constructeur. Les autres constructeurs delèguent à ce constructeur principal. Ainsi, une modification de la logique de validation n'affecte qu'un seul endroit.

Constructeur ou setter ?

L'initialisation des données obligatoires doit se faire dans le constructeur. Les données optionnelles peuvent être passées au constructeur (avec valeur par défaut) ou via des setters. Un objet ne devrait jamais exister dans un état invalide.

Ordre recommandé dans une classe ​

java
public class MaClasse {
    // 1. Constantes
    private static final int MAX = 100;

Exemple complet - Billet d'avion
java
public class BilletAvion {

    private String origine;
    private String destination;
    private String classeService;
    private boolean avecBagage;

    // Constructeur principal
    public BilletAvion(String origine, String destination,
                       String classeService, boolean avecBagage) {
        if (origine == null || origine.isBlank()) {
            throw new IllegalArgumentException("L'origine est requise.");
        }
        if (destination == null || destination.isBlank()) {
            throw new IllegalArgumentException("La destination est requise.");
        }
        if (origine.equals(destination)) {
            throw new IllegalArgumentException("Origine et destination doivent être différentes.");
        }
        this.origine = origine;
        this.destination = destination;
        this.classeService = classeService != null ? classeService : "économique";
        this.avecBagage = avecBagage;
    }

    // Constructeur pratique - économique, sans bagage
    public BilletAvion(String origine, String destination) {
        this(origine, destination, "économique", false);
    }
}
