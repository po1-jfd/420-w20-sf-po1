IntelliJ IDEA ​

Intellij IDEA est l'environnement de développement intégré (IDE) recommandé pour ce cours. Il offre des outils puissants pour écrire, déboguer et refactoriser du code Java efficacement.

Objectifs d'apprentissage ​

Après cette section, tu seras capable de...

  • Installer et configurer Intellij Community Edition
  • Naviguer dans les fenêtres principales de l'IDE
  • Utiliser les raccourcis clavier essentiels
  • Lire et interpréter les messages d'erreur et avertissements
  • Configurer l'IDE pour le cours (désactiver certaines fonctions automatiques)

Installation ​

Télécharge Intellij IDEA Community Edition (gratuite) depuis jetbrains.com/idea. La version Community suffit pour tout le cours.

Configuration du cours

Le cours fournit un fichier de paramètres à importer dans Intellij. Ce fichier configure les raccourcis, le style de code et les inspections conformément aux normes du cours.

Pour importer : File → Manage IDE Settings → Import Settings

Lecture des messages d'erreur ​

Intellij souligne les problèmes directement dans le code :

  • Rouge : erreur de compilation - le code ne peut pas s'exécuter
  • Jaune : avertissement - le code fonctionne mais pourrait être amélioré
  • Gris : code inutilisé ou superflu

Utilise Alt+Entrée

Quand Intellij souligne quelque chose, place le curseur dessus et appuie sur Alt+Entrée pour voir les suggestions de correction. C'est souvent plus rapide que de chercher la solution manuellement.

Configuration recommandée ​

Désactiver la complétion automatique en ligne ​

Pour favoriser l'apprentissage et éviter que l'IDE complète le code à ta place :

File → Settings → Editor → General → Inline Completion → décocher « Enable local Full Line completion suggestions »

À éviter en apprentissage

Ne laisse pas Intellij écrire le code à ta place. Utilise la complétion pour vérifier les noms exacts, mais tape le code toi-même pour mieux retenir la syntaxe.

Configuration

Pour procéder à l’importation des réglages pour le cours de Programmation Objet I, lance Intellij puis va dans le menu File > Manage IDE settings > Import Settings..., importe le fichier de configuration disponible sur Léa

Les réglages proposés incluent les règles de formatage pour le code, l’activation d’éléments d’assistance pour l’apprentissage de l’éditeur de code et la désactivation d’autres éléments pouvant nuire à l’apprentissage (notamment, mais pas exclusivement, les outils d’intelligence artificiels pour la génération de code)
